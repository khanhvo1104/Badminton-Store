## Formats

- UTF-8, header row
- Booleans: `true` / `false`
- Money: `1890000.00` (no thousand separators)
- Timestamps: ISO-8601 UTC (`2026-06-01T00:00:00Z`)
- JSON: `specifications_json` column on products
- Empty string = SQL NULL for optional fields

## Dashboard / remote CSV

Import each CSV in order with upsert on primary key (`id` / `variant_id`).

Do **not** put the service_role key in Flutter.

## Image paths

CSV paths are Storage placeholders, e.g.:

`product-images/<product-id>/main.webp`

Upload real files to buckets later; seed does not download images.
